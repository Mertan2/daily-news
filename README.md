# Daily News Briefings

Automated daily, weekly, and topic-focused news briefings, generated by a Claude Code scheduled task.

**Live site:** https://mertan2.github.io/daily-news/

## Reports

- `daily-briefing.html` — fresh each day, broad news across US, Europe, Turkey, China, Japan (target: 120 sources).
- `weekly-report.html` — edited each day, accumulating context across the week.
- `specific-topics.html` — driven by `request.md` (interests list, kept local — not published).
- `learning-goals.html` — only present when `learngoals.md` is set locally.

## How it works

A scheduled task fires daily. It reads `request.md` (and `learngoals.md` if present) locally, sweeps 30–40 sources per region, and rewrites the three HTML reports. The final step calls `publish.sh` to commit and push.

## Disclaimer

Automated news summaries from public sources at generation time. Verify with the original outlet before acting on anything.
